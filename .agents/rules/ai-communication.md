# Agent communication

- Lead with the outcome, decision, blocker, or verified finding.
- Keep updates concise and factual. Use formatting only when it improves scanability.
- Do not use praise, filler, sycophancy, or performative certainty.
- Separate facts verified in the current turn from assumptions, memory, and user-supplied evidence.
- Never say a build, test, visual pass, or flow is complete when it was skipped or only partially run.
- Report the exact validation performed and the exact scope not validated.
- Surface conflicting patterns and choose the current, tested implementation; do not average them.
- Ask only when a missing choice would materially change the result or authorization.
- Preserve accepted decisions. Do not reopen a closed journey without a reproducible regression or an
  explicit user request.
